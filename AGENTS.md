# Правила проекта

- Перед работой прочитай `SPEC.md` и актуальные файлы в `contracts/`.
- Разработчик A ведёт `backend/`, `scripts/`, `data/`, `contracts/` и общие файлы. Разработчик B ведёт `frontend/`. Изменения за пределами своей зоны согласуй с её владельцем.
- Работай в отдельной ветке. Обновляй `main` через небольшие PR. Перед изменением форматов CSV или API согласуй правку с обоими разработчиками.
- Реализуй текущий этап. Используй терминологию и формулы из `SPEC.md`.
- Перед передачей запусти проверки, доступные для текущего этапа. Укажи команды, результаты и проверки, которые не удалось запустить.
- Не коммить секреты, локальные базы, зависимости и CSV с реальными результатами школьников.
