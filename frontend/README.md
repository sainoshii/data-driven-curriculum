# Панель методиста

Локальный каркас на React, Vite и TypeScript. Требуется Node.js 22.12+ (или 20.19+) и npm.

```sh
cd frontend
npm install
npm run dev
```

Адрес разработки: http://127.0.0.1:5173 (если порт занят, Vite напечатает другой).

```sh
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт `dist/`. `preview` показывает готовую сборку.

«Открыть демо» выполняет `POST /api/datasets/demo`, затем запрашивает обзор с `dataset_id` из ответа. Выбор школы передаёт `school_id`, «Все школы» убирает параметр. Пункты фильтра приходят из `dataset.school_ids`. «Учебники» и «План часов» остаются заглушками.

Вкладка «Темы» использует уже открытый набор и общий фильтр школы с «Обзором». `CurriculumApi.getTopics` получает `GET /api/datasets/{dataset_id}/topics` с необязательным `school_id`. Таблица и тепловая карта сортируют темы по точной доле ниже порога (по убыванию, при равенстве — `topic_id`); `null` ставится после чисел и отображается как «Нет данных». Нулевой результат сохраняется как 0. Размер выборки — число пар ученик–тема.

Карта содержит все сочетания школ и тем выбранного среза; пропущенная ячейка обозначается «Нет данных». Цветовая шкала описывает долю ниже порога, проценты также видны в каждой ячейке. Карта прокручивается горизонтально с клавиатуры, коды тем расшифрованы в таблице и названиях столбцов. Для демо ожидается 5 × 25 ячеек, для S01 — 1 × 25. При загрузке показывается статус, при ошибке — повтор. Ответ старого запроса после смены вкладки или среза игнорируется.

`src/data/curriculum.ts` задаёт асинхронный интерфейс `CurriculumApi` и HTTP-адаптер. Ошибки соединения, HTTP и ответа показываются с кнопкой «Повторить». Запрос ограничен 15 секундами. При ошибке фильтра сохраняется предыдущий успешный срез; повтор запрашивает выбранную школу. В `src/data/mocks/` сохранены примеры контракта для справки, приложение их не использует.

Перед запуском фронтенда поднимите FastAPI из корня репозитория по основному README. Используйте стабильный Python 3.11+. Пример для Windows с Python 3.12 и локальным окружением внутри `frontend/`:

```powershell
py -3.12 -m venv frontend/.venv-api
frontend/.venv-api/Scripts/python -m pip install -r backend/requirements.txt
frontend/.venv-api/Scripts/python -B -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Vite проксирует `/api` на `http://127.0.0.1:8000` при `npm run dev`. Для развёрнутой сборки нужен серверный reverse proxy с тем же маршрутом `/api`; `dist/` сам по себе не включает FastAPI.

Проценты из `below_threshold_pct` отображаются без умножения на 100. Для отображения используется русская локаль и округление до двух знаков; темы сортируются до округления. `null` показывается как «Нет данных», отдельно от нуля. Число учеников и число результатов (пар ученик–тема) подписаны отдельно. Признак демо берётся из `dataset.is_demo`. CSV и остальные разделы пока не подключены.
