# Панель методиста

Локальный каркас на React, Vite и TypeScript. Требуется Node.js 22.12+ (или 20.19+) и npm.

```sh
cd frontend
npm install
npm run dev
```

Адрес разработки: http://127.0.0.1:5173 (если порт занят, Vite напечатает другой).

```sh
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт `dist/`. `preview` показывает готовую сборку.

На текущем этапе «Открыть демо» загружает обзор из моков. Фильтр поддерживает «Все школы» и «S01»; остальные разделы остаются заглушками.

`src/data/curriculum.ts` задаёт асинхронный интерфейс `CurriculumApi` и моковый адаптер. В `src/data/mocks/` лежат точные копии трёх примеров из `contracts/examples/`. После изменения контракта обновляйте копии вместе с адаптером.

Для подключения FastAPI замените реализацию `openDemoDataset` на `POST /api/datasets/demo`, а `getOverview` — на `GET /api/datasets/{dataset_id}/overview` с необязательным `school_id`. Пустой фильтр означает отсутствие параметра. При подключении остальных школ расширьте `supportedSchoolIds`; пункты фильтра берутся из `dataset.school_ids`.

Проценты из `below_threshold_pct` отображаются без умножения на 100. Для отображения используется русская локаль и округление до двух знаков; темы сортируются до округления. `null` показывается как «Нет данных», отдельно от нуля. Число учеников и число результатов (пар ученик–тема) подписаны отдельно. Признак демо берётся из `dataset.is_demo`. CSV, расчёты и запросы к реальному серверу пока не подключены.
